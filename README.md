## 无 root 版 1.2

支持 Android 8.0 及以上。普通手机可使用电量与高温提醒、预约、用量分析与桌面组件。Home Assistant 充电插座和 Shizuku 驱动支持可以分别启用。

- [查看对应提交](https://github.com/RC-9246/rootward/tree/62350af7524fec62e873865699f2d5d860e95ff6/shizuku)
