# 归根 · 签名安装包

支持 Android 8.0 及以上。普通手机可使用电量与高温提醒、预约、用量分析与桌面组件。Home Assistant 充电插座和 Shizuku 驱动支持可以分别启用。

- [下载无 root 版源码](https://raw.githubusercontent.com/RC-9246/rootward/downloads/shizuku-v1.2/Rootward-Shizuku-1.2-source.zip)
